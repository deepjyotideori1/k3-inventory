<analysis>original_problem_statement:
Build an Inventory Dashboard for K3 GAS SERVICE with the tagline Khayal Hamesha. The dashboard should be professional and manage inventory for an initial set of 5 warehouses, with the ability to add more warehouses and stock items in the future.

**PRODUCT REQUIREMENTS:**
-   **Authentication:** Separate login credentials for a master admin and individual warehouse managers.
-   **Warehouse Reports:** Warehouse managers submit daily reports for 15kg and 21kg cylinders. The form should include opening balance, units sold, units sent for refilling, and a manager's physical count of the closing stock. The system must calculate the expected closing stock and highlight any discrepancies.
-   **Plant Hollongi Report:** A special report format for the Plant Hollongi warehouse to track a main bullet tank and cylinder stock, including deliveries to and from other warehouses.
-   **Dealer Report:** For Plant Hollongi, a system to manage dealers, track date-wise issuance and refilling of 15kg and 21kg cylinders, and generate aggregated PDF/Excel reports.
-   **LPG Accessories Report:** For the Master Admin, a system to manage accessories and dealers, tracking issued, sold, and remaining quantities.
-   **Customer Management (New):** A dashboard for all warehouses to manage customer data (Domestic/Commercial). Includes adding single customers, bulk uploading via Excel, and PDF/Excel exports. The master admin can edit/delete and view customers from all warehouses.
-   **Order Generation (New):** A dashboard for warehouses (except Plant Hollongi) to create daily orders. Features include warehouse-specific sequential order numbers (A1, A2...), selecting existing customers or adding new ones, and generating reports (Daily, Weekly, Monthly, Yearly).
-   **Order Status Tracking (New):** An enhancement to the Order Generation module to track and update order status from Pending to Delivered.
-   **Bulk Messaging (New):** A placeholder UI for the master admin to send bulk SMS or WhatsApp messages to customers, with a backend structure ready for future integration with a messaging API.
-   **Master Dashboard:** A consolidated view of all warehouse data with discrepancy alerts. The master admin can update initial stock, add new warehouses, and add new stock items.
-   **Features:**
    -   Data from warehouse reports should sync across relevant modules.
    -   Daily reports must have Save as Draft and Edit options.
    -   Reports must be downloadable in PDF and Excel formats.
    -   An admin-controlled Under Maintenance mode.
    -   The business logo should be displayed on the dashboard.

**User's preferred language**: English
