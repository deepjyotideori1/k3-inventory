### original_problem_statement
Build an Inventory Dashboard for K3 GAS SERVICE with the tagline Khayal Hamesha. The dashboard should be professional and manage inventory for an initial set of 5 warehouses (Jullang, Naharlagun, Doimukh, Plant Hollongi, etc.), with the ability to add more warehouses and stock items in the future.

**PRODUCT REQUIREMENTS:**
-   **Authentication:** Separate login credentials for a master admin and individual warehouse managers.
-   **Warehouse Reports:** Warehouse managers submit daily reports for 15kg and 21kg cylinders (Filled/Empty). The form should include opening balance, units sold, units sent for refilling, and a manager's physical count of the closing stock. The system must calculate the expected closing stock and highlight any discrepancies against the physical count.
-   **Plant Hollongi:** This special warehouse has its own report format tracking a main bullet tank (in Kg) and cylinder stock. Its report includes data on cylinders refilled, filled cylinders delivered to other warehouses, and empty cylinders received from them.
-   **Master Dashboard:** Provides a consolidated view of all warehouse data, including discrepancy alerts. The master admin must be able to update the initial stock for any warehouse (including the bullet tank) and should have an interface to add new warehouses and stock items in the future.
-   **Features:**
    -   Data from warehouse reports (like refilling requests) should sync with the Plant Hollongi dashboard.
    -   Daily reports should have a Save as Draft option and be editable after submission.
    -   Reports must be downloadable in PDF and Excel formats.
    -   An admin-controlled Under Maintenance mode.
    -   The business logo should be displayed on the dashboard.

A full-stack React/FastAPI application with JWT authentication for a master admin and multiple warehouse managers. The system supports daily inventory reporting for regular warehouses and a specialized report for the Plant Hollongi warehouse, including bullet tank tracking. Key features like discrepancy calculation, master admin stock updates, and PDF/Excel exports are implemented. The UI includes the company logo and follows a professional green theme. The database is MongoDB, with collections for users, warehouses, and reports.
